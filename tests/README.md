# בדיקות עשן

סוויטות Playwright שמריצות את רשימת ה"בוצע" של שלב 3 (`docs/SPEC.md` §9) מול הדפדפן.
הן **אינן חלק מהאפליקציה**: אין `package.json` בשורש, ואף קובץ כאן לא נטען בזמן ריצה.
האילוץ "ללא build" (§1 באפיון) חל על האפליקציה, לא על מה שבודק אותה.

## הרצה

בסשן מרוחק של Claude Code אין צורך בכלום: `.claude/hooks/session-start.sh` מתקין
playwright בגרסה שתואמת לדפדפן שבתמונה, מייצר את שני קבצי העזר ומרים את השרת.
מה שלמטה הוא ההרצה הידנית, למי שעובד מקומית.


```bash
npm i playwright                       # פעם אחת, בשורש הריפו (node_modules ב-.gitignore)
python3 -m http.server 8777            # IndexedDB לא עובד מעל file://
node tests/units.mjs                   # 77 — ולידטורים, נרמול, bidi, טוהר הטבלה
node tests/e2e.mjs                     # 63 — זרימות מקצה לקצה
node tests/mrz.mjs                     # 42 — TD3, TD1, ספרות ביקורת, OCR אמיתי, דלג
node tests/confirm.mjs                 # 25 — מסך האישור והצעת הישויות
node tests/gemini.mjs                  # 120 — השער, המפל, התקרות, הפענוח לפי דרישה ודלג
node tests/sync.mjs                    # 40 — מיזוג, ושני מכשירים אמיתיים
node tests/drive.mjs                   # 29 — דרייב, מול Google API מזויף
node tests/bridge.mjs                  # 52 — גשר Apps Script, מול גשר מזויף
node tests/pwa.mjs                     # 37 — גרסה, SW, אופליין אמיתי, PDF
node tests/features.mjs                # 257 — התיקונים של 0.9.x
node tests/keyfile.mjs                 # 49 — קובץ המפתחות, ושני מכשירים
```

סה״כ **791 בדיקות**.

node מחפש את `playwright` מהתיקייה של הסקריפט כלפי מעלה, ולכן ההתקנה חייבת להיות
בשורש הריפו ולא במקום אחר.

משתני סביבה: `BASE` (ברירת מחדל `http://127.0.0.1:8777/index.html`), `CHROME` (נתיב
לדפדפן, אם אינו מותקן במקום הרגיל), `FIXTURES` (תיקייה לקבצי עזר; `e2e.mjs` צריך שם
`shot.png`, ו-`pwa.mjs` צריך `policy.pdf`), `ROOT` (שורש הריפו ל-`pwa.mjs`).

שני קבצי העזר אינם בריפו ואינם צריכים להיות אמיתיים: `shot.png` היא תמונה כלשהי,
`policy.pdf` הוא PDF כלשהו עם עמוד אחד שיש עליו דיו.

## מה נבדק

**`e2e.mjs`** — יצירת ישות · מסמך ידני מכל 12 הסוגים · העתקה בנגיעה כולל שורה ממוסכת
(מוודא שהערך המלא נכנס ללוח ושהמסך לא נחשף) · שדה שנכשל בוולידציה נשמר ומסומן ·
חיפוש גלובלי · ארבעת מסלולי הקלט · דליי התפוגה כולל `daysLeft === 0` · חישוב חוצה שעון קיץ ·
התמדה אחרי רענון · החלפת פלטה וכתב · שער PIN מקצה לקצה כולל כיבוי · אפס שגיאות קונסול.

**`units.mjs`** — ספרת ביקורת של ת״ז · פורמט לוחית 7 ו-8 ספרות · תאריכים · טלפון ·
מיסוך · `copyAs` · נרמול תמונות בארבעה מקרים כולל הכלל שנרמול לא מגדיל קובץ ·
דחיית קובץ שבור · **עותק לשליחה** (DEC-44): הקטנה לצלע שבקונפיג, מקור שאינו נוגע,
הקטנה שאינה מייצרת קובץ שמן יותר, ו-PDF שנשלח כמות שהוא · **אפס בקשות לדומיין חיצוני** · **`screens.js` ו-`forms.js` אינם מזכירים
אף מפתח סוג מסמך** — זו הבדיקה ששומרת על הכלל הארכיטקטוני של `DOC_TYPES`.


**`mrz.mjs`** — פרסינג TD3 ו-TD1 מול דגימות שנבנות עם ספרות ביקורת תקינות · חמש סיבות כשל
מובחנות · תיקון מילוי שספרת הביקורת שופטת, כולל מקרה שבו תיקון **לא** מציל קריאה שגויה ·
חילוץ ת״ז מ-optional data · **קריאה אמיתית מתמונה דרך Tesseract מקומי** · אפס בקשות חיצוניות ·
**דלג בקריאה שרצה על המכשיר** (DEC-43): הטופס נפתח מיד ולא בעוד שניות, והקריאה שממשיכה
ברקע **אינה מציבה את ההצעה שלה ואינה מוחקת את הצילום** מתחת לטופס שכבר פתוח — הבדיקה
ממתינה לרגע שבו הקריאה באמת נגמרה, ולא להשהיה שרירותית. התוצאה המאוחרת **מוחזקת בשער**
עד שהדילוג כבר קרה: בלעדיו OCR מהיר שסיים לפני הלחיצה היה מפיל את הבדיקה על התנהגות
נכונה, וזה היה מרוץ שנראה כמו רגרסיה.

**`confirm.mjs`** — סורק צילומי מסמך אמיתיים שנוצרים על הדיסק בזמן הריצה: דרכון נקרא, הסוג
נבחר מהפורמט, הצילום לא נשמר, השם נשמר לא מאומת · תעודת זהות נקראת וה-ת״ז מחולצת ·
צילום שנכשל בספרת ביקורת מקבל הודעה שאומרת "זוהה ונכשל" ולא "לא זוהה", ואף שדה לא מולא ·
הצעת הישויות מהספח, כולל שהדילוג לא יוצר כלום.


**`gemini.mjs`** — רץ מול API מזויף דרך `page.route`; **אף בקשה אמיתית לא יוצאת ואין צורך
במפתח.** נבדק: בלי מפתח או בלי הסכמה אפס בקשות יוצאות · הפרומפט מכיל את כל 12 הסוגים ונבנה
מהטבלה · **דירוג המודלים**: `pro` לפני `flash` לפני `flash-lite`, שכבה שגוברת על דור, יציב לפני
`preview` · 429 ו-404 מפנים מקום ו-400 עוצר מיד · שהמפל חוזר להתחיל מלמעלה ואינו ננעל
על המודל שהצליח · **מפל שהמשתמש הגדיר** שגובר על הדירוג ואינו שואל את ה-API · גילוי טרי ·
טיימאאוט שקוטע בקשה תקועה · חילוץ JSON מגדרות קוד ומפטפוט · שדה שאינו בטבלה נזרק ·
תאריך שאינו קיים נדחה · **תעודה שאין לה שורה בטבלה**: הסוג הפתוח קולט את מה שהיה נזרק,
התווית מגיעה מהמסמך, מפתח שמוכר משורה אחרת מקבל את התווית שלה, סוג סגור אינו אוסף כלום,
ותקרת ה-20 · הסכמת טקסט אינה מתירה שליחת צילום · דיאלוג ההסכמה, וביטול שאינו מדליק אותה ·
**דלג** (DEC-43): דילוג לפני השליחה שאינו מוציא אף בקשה, דילוג באמצע בקשה תלויה שאינו
מתחזה לטיימאאוט, הכפתור בגיליון ההמתנה שפותח את מסך המסמך מיד ומשאיר את הקובץ מצורף
ואת השדות ריקים, Escape שמתנהג כמוהו, וכישלון אמיתי שעדיין אומר "הפרסינג נכשל" בזמן
שדילוג אינו אומר ·
**התקרות** (DEC-44), ובראשן הבדיקה שמכסה את הדיווח: **מודל שנתקע אינו מפיל את המפל**
והבא בתור עונה · תקרה לניסיון מול תקרה לכל, שאומרות שני דברים שונים · שלושה ניסיונות
ולא עשרות · `400` סתמי שממשיך לבא בתור מול `400`/`401` על המפתח שעוצרים מיד ·
`finishReason` שמבדיל בין מודל שסירב לקרוא תעודה, תשובה שנקטעה ותשובה ריקה ·
רשימת המודלים ששורדת רענון ומוציאה את הגילוי מהמסלול הקריטי, ומתרעננת ברקע **אחרי** ·
והבקשה שיוצאת נושאת את התמונה המוקטנת ולא את המקור.


**`sync.mjs`** — הבדיקה החשובה בפרויקט. **שני browser contexts עם שני IndexedDB נפרדים**
חולקים דרייב מזויף שיושב בתהליך הבדיקה, ומריצים סבב אמיתי: יצירה ב-A · סנכרון · משיכה ב-B
כולל הורדת ה-blob · עריכה נגדית ב-B וחזרה ל-A · מחיקה שמגיעה כ-tombstone.
בנוסף: כל מקרי המיזוג הטהורים · **`files[]` שאינו נדרס**, כולל קובץ שטרם עלה ששורד ·
`blobId` שנחתך בייצוא · שדות הדרכון שאינם עוזבים · המנעול נגד שתי הרצות · אופליין
שמצטבר ונתפס בהרצה הבאה · ה-debounce.

**`drive.mjs`** — Google API מזויף. איתור התיקייה בפעם הראשונה וכתיבת המצביע ל-`appDataFolder` ·
**שחזור אחרי מחיקת נתוני אתר** — המזהה המקומי נמחק והתיקייה נמצאת מחדש במקום להיווצר שנייה ·
`db.json` שנוצר פעם אחת ומעודכן אחר כך · `multipart/related` שמשמר בייטים ו-mime ·
סבב העלאה־הורדה של PNG · 401 שמנתק ומחזיר הודעה שמפנה להתחברות · סקופים.


**`features.mjs`** — עשרת הדיווחים של 0.9.0, כל אחד מול הבאג שדווח ולא מול הקוד שנכתב:
**הדבקת PDF** — באירוע `paste` אמיתי ובתוך יעד ההדבקה, שני המסלולים שבהם זה עובד,
**והדבקה שלא מסרה קובץ שאינה סוגרת את הגיליון** (הבאג שדיווח מ-iOS: הגיליון נסגר תמיד
והמשתמש נזרק חזרה בלי הסבר),
ובדיקה שמריצה `clipboard.write` עם PDF ומוודאת שהדפדפן דוחה אותו (כך שההנחה על
מגבלת ה-API לא תישחק בשקט) · שינוי שם קובץ, ב-DB ובמסך ·
**מסמך מעודכן שדוחק את הקודם** — זהות משדות החובה, סדר לפי תוקף ולא לפי העלאה,
העלאת מסמך ישן שאינה דוחקת, והישן שנשאר ומקושר · אווטאר: תמונה שלמה עם צלע קצרה קבועה, תקרת משקל, נפילה לאות,
ובורר עגול שנשמר על הישות ומצויר בכרטיס · קיבוץ לפי סוג עם אדם ראשון, וגרירה ששורדת רענון · **מה שהפיל את הגרירה בנייד**:
שהבלם על הגלילה אינו פועל לפני שהלחיצה הארוכה מבשילה ופועל מיד אחריה, שבועת הבחירה
של iOS מכובה, **ושיש ל-`UI.reorder` הגדרה אחת בלבד בקובץ** — עותק כפול דרס את החדש
וכל התיקונים לא רצו · **סדר ידני למסמכים בתוך ישות**, כולל שהוא שורד רענון ועריכה · קנה מידה נעול שנעצר בגבול
הצופה · באנר לחיץ שנעלם אחרי טיפול וחוזר כשנוסף מסמך · `object-position` בראש התמונה, **ובורר המסגרת** — גרירה, מחוון, שמירה על הקובץ,
השבתה בתמונה רחבה, ומעבר בטוח דרך הייצוא והמיזוג · **ההגדלה** (DEC-46): מחוון שמגדיל,
`transform-origin` שזהה ל-`object-position` כך שההגדלה אינה מחליקה מהנקודה שנבחרה,
המעטפת שחותכת את מה שגלש, הגדלה ששורדת שמירה ופתיחה מחדש, חזרה ל-100 שאינה משאירה
`scale(1)`, הגדלה שפותחת מקום לתזוזה בציר שלא היה בו, ושלושת המספרים בייצוא ובמיזוג
כולל קובץ ישן שחוזר עם `focusZ: 1` ולא עם אפס ·
שיתוף, כולל נפילה להורדה ושם קובץ תקין · **העוזר**: הסכמה נפרדת, הדרכון שאינו עוזב
את המכשיר גם שם, וששת מסלולי הפסילה של `Chat.compile` — כולל שקימפול לבדו אינו כותב כלום — ומה שהתקבל
מנאביגו: `SAFE` שמסמן רק את הבטוח, הערך הקודם בכרטיס, הדחייה שחוזרת למודל, `daysLeft`
ו-`counts` מחושבים מראש, וצמצום מסמך שפג מזמן לשורה בלי שדות.
בסופה, אותו באג של המסמך המעודכן **דרך הטופס**, בכספת נקייה, מקצה לקצה ·
**תעודה שאין לה שורה בטבלה, דרך הטופס** — ש"הוספת שדה" קיים בסוג פתוח ואינו קיים בסוג
סגור, ששדה שנוסף ביד נשמר ומוצג כמו כל שדה אחר, ששורה חצי-ריקה אינה הופכת לשדה,
שעריכה חוזרת טוענת אותו במקום למחוק אותו, שהסרה מורידה אותו, ושהצעת פרסינג מציירת
את השדות ומעבירה אותם למסמך · **ומה שמסך ההגדרות אומר על הדרייב** — שאין בו יותר
טענה שגיבוי לדרייב לא קיים, בזמן שהמסך עצמו מציע להגדיר אותו ·
**הכפתור "חזור"** — שהטופס יורד מההיסטוריה אחרי שמירה ולחיצה אחת מחזירה לישות ולא
לטופס, שעריכה חוזרת למסמך בלי עותק כפול שלו, שמסמך מחוק אינו יעד לחזרה, ושקישור
שנפתח ישירות נופל להורה הלוגי במקום לצאת מהאפליקציה ·
**מסך הבית שנגזר מהתמונה** (DEC-39) — שתי קבוצות ולא ארבע, תווית שנבנית מהסוגים שיש
להם ישויות, `avatarImage` שממלא עיגול של 64 עם המסגרת שנבחרה, טבעת בצבע הדלי לישות
שדורשת מבט ואפס צבע לישות רגועה, פס תמונה עם תווית הסוג לנכס, `Expiry.next`
ו-`Expiry.shortLabel`, ושורת המצב שמחליפה את הבאנר — לצד הבאנר עצמו, שעדיין נבדק
במסלול שבו מסך התפוגות הוא מסך הבית · **גרירה בשני צירים** — רצועה אופקית ולוח דו-טורי ·
**תמונה רחבה שנכנסת שלמה לעיגול** (DEC-41) — ריפוד לריבוע בייבוא, שני קצוות המקור
ששורדים את החיתוך, ריפוד שנדגם מהרקע של התצלום, ותמונה 4:3 או אנכית שאינה מרופדת ·
**המשוב בגרירה** — שההמתנה נראית ומתקדמת, שהכרטיס הנישא הולך אחרי האצבע ולא קופץ
משבצת לשבצת, ש-FLIP נועל את השכן למקומו הישן ומשם מנפיש אותו, שהנחיתה מנקה כל
סגנון inline, ושהנחה במקום אינה מכריזה שהסדר נשמר.

**השיוך של מסמך חדש** (DEC-45) — הדיווח "המסמך נשמר על הישות הראשונה ולא על זו
שממסכה הוספתי": ה-FAB במסך ישות, גם כשכבר יש בה מסמכים ואין בה מצב ריק · מסך
הבית שאין בו הקשר ולכן נשארת ברירת המחדל · קובץ שנגרר למסך ישות · טופס פתוח
שהחלפת קובץ בתוכו אינה מאפסת את השיוך שנבחר בו · ובורר קבצים אמיתי שהפרסינג בו
נכשל, שנשאר על אותה ישות — המסלול של הדיווח החוזר.

**`bridge.mjs`** — התחבורה שאינה מבקשת התחברות, מול Apps Script מזויף. נבדק:
שהחיבור שורד רענון בלי פופאפ · **שהבקשה נשארת "פשוטה"** — POST בלי `Content-Type`
של JSON ואפס `OPTIONS`, כי preflight הוא מה שמפיל את הגשר בשקט · סבב מלא של
`db.json` ושל blob, כולל שהבייטים חוזרים זהים דרך base64 · תקרת הגודל שנעצרת בצד
הלקוח · ארבעה מסלולי כשל שכל אחד אומר משהו אחר (סוד שגוי · תשובת HTML שפירושה
כתובת לא נכונה · שגיאת HTTP · רשת נופלת) · ששתי התחבורות מממשות את אותן חמש
